# Autoescuela BIANCO (EcoBianco Albacete)

Sitio web oficial de **Autoescuela Bianco / EcoBianco** en Calle de la Feria, nº 129 - 131, Albacete.

## Estructura del Proyecto

```
├── index.html              # Sitio estático optimizado y autocontenido
├── assets/
│   └── images/
│       ├── brand/          # Logotipo oficial y favicon
│       ├── hero/           # Imágenes principales de portada (desktop y mobile)
│       ├── installations/  # Fachada física del centro en Calle Feria
│       └── students/       # Fotos de alumnos aprobados con su placa 'L'
├── docs/                   # Documentación y dossiê estratégico del proyecto
├── .gitignore
└── .vercelignore
```
